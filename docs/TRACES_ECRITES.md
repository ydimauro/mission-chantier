# Traces écrites (cahier papier)

L’application ne remplace jamais le cahier. Ce document rassemble, pour chaque mission obligatoire, ce que l’élève doit concrètement écrire sur papier (voir détail complet mission par mission dans `docs/SEANCES_5E.md` et `docs/SEANCES_4E.md`, champ « Trace écrite »). Objectif global : environ une page A4 par séance, jamais de recopie de long paragraphe.

## 1. Structure recommandée

Lorsqu’elle est pertinente, la structure suivante organise la trace écrite d’une mission :

- Ce que je pense ;
- Ce que j’observe ;
- Ce que je teste ;
- Ce que je comprends ;
- Ce que je retiens.

## 2. Récapitulatif 5e

| Mission | Nature de la trace écrite |
| --- | --- |
| 5E-00 | Titre de mission + réponse personnelle à la problématique initiale (conservée, reprise en 5E-12) |
| 5E-01 | Tableau besoin / utilisateur / objet ou système / contrainte |
| 5E-02 | Tableau besoin / fonction / solution |
| 5E-03 | Tableau des fonctions principales des engins |
| 5E-04 | Tableau de comparaison + justification du choix |
| 5E-05 | Schéma matière / énergie / information (MEI) |
| 5E-06 | Chaîne énergie → conversion → mouvement |
| 5E-07 | Plan annoté ou liste des zones avec justification |
| 5E-08 | Hypothèse / résultat / conclusion |
| 5E-09 | Schéma capteur → information → traitement → action + programme modifié |
| 5E-10 | Recopie du programme final avec légende des blocs |
| 5E-11 | Tableau comparatif + phrase de conclusion sur les compromis techniques |
| 5E-12 | Synthèse structurée (besoin, contraintes, choix, résultat, justification) + relecture du cahier de 5E-00 |
| 5E-FINAL | Synthèse courte de la démarche suivie |

## 3. Récapitulatif 4e

| Mission | Nature de la trace écrite |
| --- | --- |
| 4E-00 | Réponse personnelle conservée (reprise en 4E-11) |
| 4E-01 | Schéma légendé + phrase sur l’évolution des systèmes |
| 4E-02 | Chaîne d’énergie complète et composants associés |
| 4E-03 | Schéma pompe → fluide → distributeur → vérin → mouvement + observation |
| 4E-04 | Chaîne d’information complète, composants associés |
| 4E-05 | Tableau symptôme / hypothèses / tests / cause retenue / solution |
| 4E-06 | Recopie du programme final avec légende des blocs |
| 4E-07 | Tableau comparatif de deux organisations + choix justifié |
| 4E-08 | Protocole rédigé + tableau de mesures + conclusion (seuil, limites) |
| 4E-09 | Tableau comparatif multicritère + conclusion nuancée |
| 4E-10 | Proposition + résultat de simulation + justification |
| 4E-11 | Synthèse structurée (capteur, diagnostic, simulation, optimisation) + relecture du cahier de 4E-00 |
| 4E-FINAL | Synthèse courte de la démarche suivie |

## 4. Fiche de cours aménagée

Chaque séance peut proposer une version imprimable « Fiche de cours aménagée » : titres préparés, phrases à compléter, tableaux, schémas partiellement préparés, mots-clés, zones de réponse courtes. Le détail par mission figure dans `docs/SEANCES_5E.md` et `docs/SEANCES_4E.md` (champ « Fiche de cours aménagée »).

Règle de confidentialité stricte : aucune mention du motif pour lequel un élève utilise cette version n’est jamais enregistrée nulle part (ni dans `.mcjson`, ni dans `.mcconfig`, ni dans les logs). Voir `docs/RGPD.md`.

## 5. Volume total estimé

25 séances obligatoires au total (14 en 5e, 13 en 4e, avec 2 missions RECOMMANDÉES) ; volume de trace écrite cible d’environ une page A4 par séance, soit un cahier d’environ 25 pages sur l’ensemble du parcours complet, cohérent avec un usage réaliste sur l’année (voir `docs/PROGRESSION_ANNUELLE.md`).
