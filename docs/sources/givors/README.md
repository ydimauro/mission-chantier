# Sources locales sur Givors

Ce dossier contient les documents de référence utilisés pour le cas réel « Givors se transforme ».

## Types de documents acceptés

- pages ou captures officielles de la Ville de Givors ;
- documents de la Métropole de Lyon ;
- PDF institutionnels ;
- plans ;
- photographies de panneaux de chantier ;
- photographies personnelles ;
- documents publics pertinents.

## Règles

1. Les faits présentés comme réels dans l’application doivent provenir de ce dossier.
2. Une information absente ne doit jamais être inventée.
3. Les affirmations institutionnelles doivent être attribuées : « Selon la Ville de Givors… ».
4. Si deux documents se contredisent ou concernent des dates différentes, documenter l’écart au lieu de trancher silencieusement.
5. Ne pas republier automatiquement ces fichiers dans un dépôt public.
6. Pour les photographies : éviter ou flouter les visages identifiables, enfants, plaques d’immatriculation et données personnelles visibles.
7. Les médias qui peuvent réellement être distribués avec l’application doivent être copiés volontairement dans `public/givors/` après vérification des droits.

Ce dossier doit rester ignoré par Git, sauf ce fichier README.
